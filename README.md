## What is this?

_Distilling a human_ means training an AI to think, speak, and decide like a specific person, using their chat logs, documents, and behavioral patterns. The result is an AI Skill that replicates their judgment and communication style — not just their knowledge.

## Persona Projects

### By Role

- [colleague-skill](https://github.com/titanwings/colleague-skill) — Train an AI from a former colleague's work documents and chat logs. [6,802 ★]
- [ex-skill](https://github.com/therealXiaomanChu/ex-skill) — Distill a former partner into a memory-preserving skill. [2,239 ★]
- [ex-skill](https://github.com/perkfly/ex-skill) — 5-layer personality model + attachment style analysis. [362 ★]
- [yourself-skill](https://github.com/notdog1998/yourself-skill) — Distill your own chat logs and documents into a personal AI. [395 ★]
- [senpai-skill](https://github.com/zhanghaichao520/senpai-skill) — Preserve senior colleague's experience as a reusable skill. [35 ★]
- [huaxia-wisdom](https://github.com/liangjfblue/huaxia-wisdom) — Chinese classical wisdom distilled into AI personas. [87 ★]

- [boss-skill](https://github.com/nicepkg/boss-skill) — PUA detection, counter-coaching, and flip-chart identification. [35 ★]
- [supervisor](https://github.com/ybq22/supervisor) — Preserve retired mentor's guidance as an always-available AI. [56 ★]

### Universal Frameworks

## Data Collectors

Platform-specific tools and methods for exporting chat logs and documents.

- **WeChat** — WechatExporter and similar tools
- **Feishu** — Official API / browser export / MCP
- **DingTalk** — Export tools available
- **iMessage** — Direct access via macOS `chat.db`
- **Twitter / X** — API scraping
- **Weibo** — JSON / HTML export
- **Xiaohongshu** — JSON export
- **Douban** — JSON / HTML export
- **Instagram** — JSON export
